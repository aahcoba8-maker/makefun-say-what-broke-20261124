Entry for the [make.fun bounty "Say What Actually Broke"](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5): one line of software error copy (at most 200 characters) that tells the user the brutal truth about what went wrong — and makes them laugh on the way.

## The line

> Nothing broke. Your 2 GB file is 40 times the 50 MB limit. Upload the smaller one and you'll be done in 3 seconds.

122 characters. It names the real failure (the file is 40x over the limit, nothing actually broke) and hands the reader a fix that works in seconds — the kind of dialog a team would actually ship.

## Run

```sh
python3 main.py
```
